# Lenqo demos

These recordings show the actual Lenqo interface with Margin, a fictional notebook website. Captions, click cues, camera zoom, and the end card are editorial additions, not Lenqo features. No customer data is shown. Mobile viewports are browser emulations, not physical-device tests.

## English walkthrough · 32 seconds

[![Watch the Lenqo walkthrough](demo-poster.png)](lenqo-walkthrough-en.mp4)

[Watch the video](lenqo-walkthrough-en.mp4) · [Download MP4](https://github.com/wadakatu/lenqo/raw/refs/heads/main/media/lenqo-walkthrough-en.mp4) · [Set up Lenqo](../README.md#first-review)

### Text description

1. Compare desktop and mobile screenshots in the same workspace, then filter each viewport.
2. Open the mobile full-page capture and scroll to inspect the rest of the page.
3. Select Field notes and switch to Live Preview. The selected page stays the same.
4. Follow the demo site's back link and switch between mobile and desktop previews.
5. Choose a position on the page and save: “Give this heading a little more breathing room.” The pin and comment stay associated with the route and viewport.
6. The end card introduces Lenqo and shows `npm i -D lenqo @playwright/test` as the installation command. Follow the README for the remaining setup steps.

## 日本語の紹介動画 · 15秒

[動画を見る](lenqo-social-ja.mp4) · [MP4をダウンロード](https://github.com/wadakatu/lenqo/raw/refs/heads/main/media/lenqo-social-ja.mp4)

### 動画の内容

1. 「AIが作った画面、自分の目で確認。」PCとモバイルの画面を並べて表示し、モバイルのみの表示へ切り替えます。
2. 「眺めるだけでなく、そのまま操作。」Live Previewへ切り替え、実際のリンクから別ページへ移動します。
3. 「気になる場所へ、直接コメント。」画面上の位置を選び、「見出しの余白をもう少し広く。」と保存します。保存したコメントへズームします。
4. 「見て、触って、フィードバック。」Lenqoの紹介、インストールコマンド、GitHubのURLを表示します。

## Files and playback

Both videos are silent H.264 MP4 files with 30 fps and progressive playback metadata. The English version is 1440 × 1080; the Japanese version is 1080 × 1350. Use the player controls to pause, seek, or enter full screen. If your browser cannot play a video on GitHub, use the download link and a local video player.

These media files are documentation assets and are excluded from the npm package's `files` allowlist. Recording scripts and raw captures are not part of this publication.
